命令行：Agent 用的三条命令

开发者用网页，Agent 用命令行；两边读同一份数据，下面的输出和首页是同一个快照（2026-10-12 13:40）。每条命令都有给人看的文字与给程序读的 --json。

命令名 nbdev 是占位，未定。task new 领到的 t82 与 answers 里的答案是示例：本机还没有登记表与答案文件。

nbdev status

全局概况：等你处理、进行中的 Task、在跑、checkout 的提醒。

zsh · neuro-book

            
nbdev status --json

        


        

            
nbdev task new
领一个 Task 号并建出最小 README；领号前把所有分支与 checkout 里已用的号扫一遍。
示例

            
zsh · neuro-book

            
nbdev task new … --json

        


        

            
nbdev answers
读开发者在面板上提交的答案；读完标为已读，答案文件本身只追加、不改。
示例

            
zsh · neuro-book

            
nbdev answers --unread --json

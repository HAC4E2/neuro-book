待定内容文件夹里，两行之间是什么意思

现状：只有和源同一层的两行之间才是“调整顺序”。别的层的源（比如把港务局里的“周局长”拖到老温和船老大之间），或者从普通文件夹拖进来的，都当作“移入这个文件夹”，整个文件夹铺底，放下后排在最后，不在你指的位置。子树末尾（巡查员阿七和老温之间）也一律算进港务局。

A 线在哪就放哪

  1. 内容文件夹和它任意深度的子目录里，两行之间就是“放到这里”。同一层只改清单；别的层、普通文件夹或另一个内容文件夹拖来的，移动并放到这个位置，文件与清单在同一次操作里改。
  2. 子树末尾的缝同时属于几层：指针的横向位置选层，越往左越外层，插入线的起点缩进到那一层，标签写清放到谁后面。
  3. 节点行的中段仍是移入它，放在最后。
  4. 普通文件夹按名字排序，没有插入线：落在里面哪里都是移入这个文件夹（现状不变）。从内容文件夹拖到普通文件夹同理。
  5. 多选拖动：按它们在树里的先后连成一串放到那里。

B 维持现状

只有同层的两行之间调整顺序；其余情况移入后排在最后，要再拖一次排到想要的位置。

推荐 A：内容文件夹的顺序就是作者编排的顺序，指着哪里就该放到哪里；B 让跨层搬动变成两步，第一步还看不出会落在哪。A 要给文件服务的批量移动加一个“放到某项之前”的参数，Spec 里本来就写了“移入……放到指定位置”，清单与文件在同一把操作锁里一起改，不会出现文件到了、顺序没写上的中间态。

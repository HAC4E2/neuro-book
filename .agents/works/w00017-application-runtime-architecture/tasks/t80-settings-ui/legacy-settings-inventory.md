# 旧应用设置清单

t80 设计用的参照：旧应用（`packages/neuro-book-legacy`）设置界面接入产品后的最终状态（w00003 t17、t18 重做，`a3c6550f` 接线）。来源是代码，未在运行中的旧应用里核对。

主要出处：

- 分区与作用域：`app/components/novel-ide/NovelIdeSettingsDialog.vue`（`sectionItems`、`scopeOptions`）
- 配置项登记：`server/config/registry.ts`（每项带作用域、生效时机、合并方式、是否密钥、说明）
- 配置结构：`shared/dto/config.dto.ts`；桌面端：`packages/neuro-book-contracts/src/desktop.ts`
- 各分区的视图：`app/components/novel-ide/settings/sections/`

## 四档作用域

| 档 | 存在哪里 | 生效 | 放了什么 |
|---|---|---|---|
| 启动 | 状态根的 `config.yaml` | 重启后 | 整站鉴权开关 `auth.enabled`；界面只读，给出 YAML 示例让用户改文件 |
| 全局 | 工作区根 `.nbook/config.json` | 多数是下一次运行 | 模型、嵌入、Agent、主题、Web 工具、请求记录、历史 |
| 项目 | 作品的 `.nbook/config.json` | 同上 | 可覆盖：默认模型、嵌入的模型与维度、Agent 默认 Profile 与运行参数、编辑器偏好与文件关联、历史保留策略 |
| 本机 | 浏览器本地状态，不写配置文件；桌面三项由桌面端主进程保存 | 立即 | 编辑器显示偏好、推理强度；桌面端缩放、托盘、关闭行为 |

登记表里每项的字段：作用域（`boot`、`global`、`global-workspace`，最后一种是全局给值、项目可覆盖）、生效时机（`hot` 立即、`next-run` 下一次运行、`next-session` 下一个会话、`restart-required` 重启）、合并方式（整体替换或深合并）、是否密钥、说明。

两处不一致（从代码推断）：“外观”分区挂在“本机”档下，主题与明暗实际写进全局配置；“编辑器”分区的值存在浏览器本地状态里，而登记表把 `editor.markdown`、`editor.monaco` 登记成全局可被项目覆盖的配置，两处各有一份。

## 分区与选项

| 分区 | 作用域 | 选项 | 形态 |
|---|---|---|---|
| 模型服务（Provider） | 全局 | 服务商列表：名称、启用、接口类型、接口地址、API Key（密钥）、代理、超时、请求参数；每个服务商下的模型：名称、id、分组、启用、接口、推理能力、输入能力、最大输出、价格（含阶梯价）、兼容项、请求头、思考档映射；“模型发现”“Model Library”两个窗口 | 自定义两栏页，内嵌浮动窗口 |
| Agent Profile | 全局、项目 | 新会话默认 Profile（小说与用户资产两种工作区各一个）；全部 Profile 共用的模型参数默认值；运行策略默认值（摘要：开关、最大对话 token；压缩：开关、预留 token、提示词、摘要前缀；文件变更提醒：diff 字符上限）；每个 Profile 的模型与运行策略覆盖；Profile 自带的低代码设置表单 | 自定义两栏页 |
| Web 工具 | 全局 | 搜索服务的顺序；Tavily、Brave 各自的启用、API Key（密钥）、超时，Brave 另有国家与搜索语言；本地抓取：开关、超时、最大跳转、最大字节、最大字符、少于多少字符改走外部服务；Tavily 兜底：开关、超时 | 服务列表可排序，其余是表单 |
| 向量嵌入 | 全局；项目只覆盖模型与维度 | 开关、服务、模型、维度、超时、接口地址、API Key（密钥）、请求扩展参数（JSON） | 表单 |
| 费用显示 | 全局 | 展示币种（USD、CNY）；汇率显示与手动刷新（汇率不写配置） | 表单 |
| 请求记录（可观测） | 全局 | 请求记录开关、每个会话保留条数（0–10000）；配置里另有“记录请求正文”，界面没放 | 表单 |
| 密码保护 | 启动 | `auth.enabled` 的当前状态与 `config.yaml` 示例 | 只读说明页 |
| 外观（前端设定） | 显示在本机，见上 | 界面语言、主题包、明暗；推理强度（本机）；`.md` 默认用富文本还是源码打开（写全局 `editor.associations`） | 表单 |
| 编辑器 | 本机 | 正文：字体、字号、行高、正文宽度、段首缩进开关与缩进量；源码：字体、字号、行高、Tab 宽度、自动换行、小地图、行号、显示空白；两块各有“重置” | 表单 |
| 桌面应用 | 本机（桌面端） | 缩放（0.75–2）、托盘开关、关闭窗口时的行为；版本与连接方式说明 | 表单 |

不在产品界面上的：

- **模型角色**：t18 先做了界面，只在 Lab 里，没有接入产品。
- **默认模型、Agent 可见模型（带用途说明）**：配置里有（`models.default`、`agent.visibleModels`），t18 拆出的两个独立分区在 2026-09-11 删掉，现在在界面哪里编辑没有核实。
- **自定义配色库**（最多 20 套）：新应用的主题 Spec 已下线自定义主题。
- **工作区文件历史**：总开关在全局；保留天数、窗口外每天留最后一份、自动接受与天数可被项目覆盖。配置里有，没有设置界面。
- **文件关联**：扩展名到编辑器视图、到源码语言的关联，界面上只有 `.md` 默认视图一项。

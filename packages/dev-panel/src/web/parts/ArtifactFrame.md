# ArtifactFrame

产物的原页（t15 阶段 4 第 1 批，从产物页抽出来）：一个沙箱 iframe，加一行“页面是当前版本”的说明。产物页的左栏用它；第 2 批 Task 页的速览面板也用它，两处的沙箱与底色一致。地址由产物接口给（`pageUrl`，产物来源上的随机前缀地址，见 docs/panel.md 的“产物来源”），零件不拼地址、不取数。

## 布局

纵向一列：说明一行（`note` 为 `null` 或空时不画），下面 iframe 占满剩下的高度（`flex-1`）。零件自己不定高：父级给高度（产物页宽屏时是页头以下的整块，窄屏时父级给最小高度）。iframe 里的页面自己滚动，不带动外面。

## 数据

```ts
interface ArtifactFrameProps {
    /** 页面地址（产物接口的 `pageUrl`）；必填 */
    src: string;
    /** iframe 的可读名，例如“侧栏宽度方案 的页面”；必填 */
    title: string;
    /** iframe 上面的一行说明；可选，默认“页面是当前版本（磁盘上的）”，产物页传“…，切换版本只切换题表”，null 或空不画 */
    note?: string | null;
}
```

没有事件、插槽与 expose；attrs 落到外层 `section`。

## 安全与外观的理由

- `sandbox="allow-scripts allow-forms allow-popups"`，**不给 `allow-same-origin`**：产物页的脚本是 Agent 写的，同源就能读面板的 cookie、调写接口。产物来源本来就是另一个端口加随机前缀（不透明来源），沙箱再隔一层。
- `referrerpolicy="no-referrer"`：产物页里的外链不带出面板地址与随机前缀。
- 定死 `color-scheme: light` 并垫白底：产物页按亮色画、多半没有自己的底色。Chrome 只在载入时按明暗是否一致垫白底，面板切到暗色后不会重算，就成了深底黑字（t11 实现审查第 5 条）。想支持暗色的产物页自己设底色。
- 答复只经外面的表单提交：外壳不监听 iframe 发来的消息（页面自己的脚本能伪造任何取值）。

## 不支持

- 不做页内答复（推迟事项，见 w00022 后续清单）。
- 不给按版本看页面：页面文件不按版本保存，只有磁盘上的当前版本。

# TruncatedText

单行截断的长文字（t15 阶段 3e）：路径、id、分支名、sha 这类放不下时截断，被截断时悬停或键盘聚焦用 nb-ui 的 `Tooltip` 看全文；可复制时是一个按钮，点一下把全文复制到剪贴板，提示改成“已复制”。checkout 页的路径不必再横向滚动才看得全。

## 布局

行内块，最宽 100%，按父级给的宽度截断（父级要能把它收窄：表格单元格、`min-w-0` 的弹性子项）。`mono` 时用等宽字体。可复制时指针变成“复制”的样子，悬停有浅底。

## 交互

- 被截断时，悬停或聚焦显示全文（可复制时后面加“点击复制”）；没被截断、可复制时提示“点击复制”。
- 点一下（或聚焦后按 Enter、空格）复制全文；提示改成“已复制”，指针或焦点离开后恢复；读屏器经一处 live 区听到“已复制”（提示框给读屏器的副本在打开时就定了）。写不进剪贴板时提示“复制失败”，并在控制台留一条警告。
- 不可复制时是普通文字，只有被截断时才能聚焦（为了键盘也能看到全文）。

## 数据

```ts
interface TruncatedTextProps {
    /** 全文；必填 */
    text: string;
    /** 等宽字体（路径、id、分支名、sha）；可选，默认 false */
    mono?: boolean;
    /** 点击复制；可选，默认 true */
    copyable?: boolean;
}
```

没有事件、插槽与 expose；写在零件上的 attrs（`class`、`style` 在内）不生效：根是 nb-ui `Tooltip`，它的根是 reka 的 `TooltipProvider`，`inheritAttrs: false` 且不转发。要改颜色、宽度或 flex 行为，就在外面包一层带类的 `span`（文字颜色会继承下来）。

## 状态

`state:local`：是否被截断（量出来的，宽度或文字变了重量）、这次复制的结果。

## 隐藏通道理由

`env:clipboard`：复制全文是这个零件存在的目的；交给宿主的话，每个用到它的页面都要各写一遍写剪贴板与失败提示，结果更乱。属于配方偏离（受控零件加剪贴板）。

## 不支持

- 多行截断、可编辑。
- 链接：链接里的长标题用 `Tooltip` 包链接本身，不用它（它会把点击变成复制）。

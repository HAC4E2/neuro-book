# Task 135 文生图浏览器走查清单

> 执行前提：启动本地 dev server，登录后打开一个 Project，并提前准备好可用的 OpenAI 兼容 LLM Provider 与 NovelAI Provider（真实凭据）。

## 1. 工作台入口

- [ ] 鉴权关闭时，不登录也可打开文生图工作台并读取配置/Provider 列表。
- [ ] 左侧「文生图」入口可见，点击后弹出独立工作台大窗口。
- [ ] 左侧导航包含 LLM / NovelAI / 正文生图 / 角色管理 / 历史图片，切换无布局错乱。

## 2. LLM 配置

- [ ] 新建 `openai_compatible` Provider，填写名称、Base URL、API Key、模型后保存。
- [ ] 「获取模型」能拉回模型列表，并可直接选择。
- [ ] 新建 Provider 未保存时，「获取模型」也可点击并基于当前 Base URL/API Key 拉取模型或显示明确错误。
- [ ] 流式生成、发送图片、合并 System/User、重试次数、模型参数保存后重新打开仍保留。
- [ ] 流式生成、发送图片、Tagthink 回显等开关显示「已开启/已关闭」，状态一眼可辨。
- [ ] 上下文预设：新建/保存/删除条目，triggerMode、triggerWords、andTriggerWords 生效。
- [ ] 上下文预设支持导入/导出全部；可导入 chatu8 `预设名 -> {entries}` JSON 与导出的完整 JSON；全局配置支持导入/导出。
- [ ] 五个请求类型（正文生图/角色设计/角色展示/角色服装修改/Tag 修改）绑定存在。
- [ ] 测试工具能直调 LLM 并显示回复；`{{正文}}`、`{{roll 1d6}}`、变量占位符在回复链路中不报错。

## 3. NovelAI 配置

- [ ] 新建 NovelAI Provider，保存模型/采样器/噪点表/Guidance/尺寸/Steps/Seed。
- [ ] 固定提示词预设可另存、读取、删除，并可通过按钮网格直接套用。
- [ ] 「翻译固定提示词」能用 LLM 把中文字段翻译成英文 tag。
- [ ] 常用 Tag 输入可追加到正面提示词。
- [ ] 配置档案可另存、读取、删除。
- [ ] Vibe Transfer 可启用，参考图文件名写入 `imageId`；可下载 `.naiv4vibe` 文件。
- [ ] AQT/UCP 质量预设选项与福瑞数据集开关可保存。

## 4. 正文生图端到端

- [ ] 正文生图会话选择 LLM/NovelAI Provider 与章节，生成 L1 块预览。
- [ ] 「写入章节」后正文出现 `<text-to-image-prompt>` 占位符。
- [ ] TipTap 占位符卡片显示标题与「生成图片」按钮。
- [ ] 点击「生成图片」后任务入队并消费，正文占位符被替换为标准 Markdown 图片。
- [ ] 生成的图片能在历史图片分页看到，并能打开原图。

## 5. 角色视觉与头像

- [ ] 角色管理读取 `visual.json`，12 字段可编辑并保存。
- [ ] 「生成角色视觉」能调用 LLM 回填并写入 visual.json。
- [ ] 角色照片 prompt 能生成，头像生成后 photos 数组更新。

## 6. 回归检查

- [ ] 以上操作不触发控制台未捕获错误。
- [ ] 刷新页面后全局配置与 Provider 仍在。
- [ ] 云端队列相关设置不出现在界面中；队列只在本机处理。

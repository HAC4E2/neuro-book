# Illustration Workflow History Clearing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a persistent “清理已结束历史” action that hides terminal illustration-planning workflows without canceling active work or deleting continuity and publication evidence.

**Architecture:** Add one nullable display-only column to the Project SQLite workflow row. The repository owns a transactional bulk hide operation and keeps continuity/recovery queries independent from the display filter; the service and strict API expose only counts, while the existing workflow panel confirms the action and refreshes its server-owned list.

**Tech Stack:** TypeScript, Zod, Prisma 7 Project SQLite client, Nuxt/H3, Vue 3, Vitest.

## Global Constraints

- Execute this plan after the P6 plan has removed the Planning `review-candidates` stub.
- Hide only `ready|failed|canceled|stale` rows whose `activeAttemptId` is `null`.
- Never hide, cancel, or delete `queued|running|validating|applying`.
- Never filter `readContinuityBaseline()`, recovery, apply-journal, publication-evidence, or single-row reads by `historyHiddenAt`.
- `hiddenCount` means rows changed from visible to hidden by this request; replay returns `0`.
- `activeCount` counts `queued|running|validating|applying` regardless of `activeAttemptId`.
- `protectedTerminalCount` counts terminal rows whose `activeAttemptId` is not `null`.
- Reusing a hidden workflow through duplicate start or retry clears `historyHiddenAt`.
- Use existing theme variables, `useDialog()`, `useNotification()`, and `resolveApiErrorMessage()`.
- Do not run browser verification automatically.
- Run every `bun`/`bunx` command in this plan outside the sandbox, per repository
  policy.
- Project SQLite upgrades belong to
  `server/workspace-files/project-workspace.ts`; do not add an App SQLite
  migration file.

```ts
/** 持久隐藏可见终态；活动项与异常持有 activeAttempt 的终态只计数、不改写。 */
async clearHistory(input: {
    projectId: string;
}): Promise<IllustrationPlanningWorkflowClearHistoryResult> {
    const terminal = ["ready", "failed", "canceled", "stale"] as const;
    const active = ["queued", "running", "validating", "applying"] as const;
    const result = await this.client.$transaction(async (transaction) => {
        const hidden = await transaction.illustrationPlanningWorkflow.updateMany({
            where: {
                projectId: input.projectId,
                status: {in: [...terminal]},
                activeAttemptId: null,
                historyHiddenAt: null,
            },
            data: {historyHiddenAt: new Date()},
        });
        const [activeCount, protectedTerminalCount] = await Promise.all([
            transaction.illustrationPlanningWorkflow.count({
                where: {projectId: input.projectId, status: {in: [...active]}},
            }),
            transaction.illustrationPlanningWorkflow.count({
                where: {
                    projectId: input.projectId,
                    status: {in: [...terminal]},
                    activeAttemptId: {not: null},
                },
            }),
        ]);
        return {
            hiddenCount: hidden.count,
            activeCount,
            protectedTerminalCount,
        };
    });
    return IllustrationPlanningWorkflowClearHistoryResultSchema.parse(result);
}
```

```ts
import {
    IllustrationPlanningWorkflowActionRequestSchema,
    IllustrationPlanningWorkflowClearHistoryResultSchema,
} from "nbook/shared/text-to-image-illustration-workflow";
import {throwIllustrationWorkflowHttpError} from "nbook/server/text-to-image/illustration-workflow-http-error";
import {getIllustrationWorkflowService} from "nbook/server/text-to-image/illustration-workflow.service";
import {requireCurrentUser} from "nbook/server/utils/auth";
import {validateBody} from "nbook/server/utils/novel-chapter";
import {withProjectNotOpenHttpError} from "nbook/server/workspace-files/project-open-guard";

/** 隐藏当前 Project 的已结束 Workflow；活动项与审计事实保持不变。 */
export default defineEventHandler((event) => withProjectNotOpenHttpError(async () => {
    await requireCurrentUser(event);
    const request = await validateBody(event, IllustrationPlanningWorkflowActionRequestSchema);
    try {
        const result = await getIllustrationWorkflowService().clearHistory({
            projectPath: request.projectPath,
        });
        return IllustrationPlanningWorkflowClearHistoryResultSchema.parse(result);
    } catch (error) {
        throwIllustrationWorkflowHttpError(error);
    }
}));
```

```ts
/** 持久隐藏已结束历史；活动 Workflow 保持显示并继续运行。 */
async function clearFinishedHistory(): Promise<void> {
    const confirmed = await dialog.confirm(
        "清理后，已结束的规划会从列表隐藏；运行中的规划不会取消，已发布插图与连续性记录也不会删除。",
        "清理已结束历史",
    );
    if (!confirmed) return;
    clearingHistory.value = true;
    try {
        const result = IllustrationPlanningWorkflowClearHistoryResultSchema.parse(
            await $fetch<unknown>("/api/text-to-image/illustration-workflows/clear-history", {
                method: "POST",
                body: {projectPath: props.projectPath},
            }),
        );
        const activeSuffix = result.activeCount > 0
            ? `，${result.activeCount} 个运行中任务已保留`
            : "";
        notification.success(`已清理 ${result.hiddenCount} 条历史${activeSuffix}`);
        if (result.protectedTerminalCount > 0) {
            notification.warning(
                `${result.protectedTerminalCount} 条异常终态仍持有活动尝试，已保留供恢复。`,
                {title: "部分历史未清理"},
            );
        }
        await loadWorkflows();
    } catch (caught) {
        notification.error(
            resolveApiErrorMessage(caught, "清理插图规划历史失败"),
            {title: "清理失败"},
        );
    } finally {
        clearingHistory.value = false;
    }
}
```

# 文生图图片交互调整设计规格

## 目标

调整图片入口的职责边界：历史图片只用于查看生成记录，正文中的 NovelAI 图片通过双击进入后处理。

## 交互合同

### 文生图历史图片

- 单击图片打开只读的生成信息弹窗。
- 弹窗展示该资产当前已保存的正面 Prompt、负面 Prompt、模型、尺寸、Seed、来源和生成时间等生成信息。
- 弹窗不提供 Tag 修改、Reroll、局部重绘或其他会创建新生成任务的操作。
- 移除历史图片上的长按计时器、操作遮罩和“长按可执行后处理”提示。

### 正文中的 NovelAI 图片

- 单击图片不打开后处理，不修改正文。
- 双击图片打开现有图片后处理弹窗。
- 仍然只处理 `alt="NovelAI 生成图片"` 且路径属于 Project 资产的图片。
- 后处理成功后的资产替换、正文保存和当前引用定位逻辑保持不变。
- 移除正文图片的长按计时器、位移取消逻辑和相关注释/文案。

## 实现边界

- 正文入口在 TipTap 编辑器的 DOM 事件层改为 `dblclick`，继续复用现有 `asset-action` 事件和页面层资产解析逻辑。
- 历史图片新增只读详情弹窗，数据直接使用历史资产 DTO，不调用生成接口。
- 现有 `TextToImageAssetActionDialog` 继续只承担正文后处理，不与历史详情弹窗混用。
- 不改变资产 API、队列、NovelAI 请求体、正文 Markdown 格式或 CAS 替换逻辑。

## 验收与测试

- 单击历史图片能打开详情，且详情中没有后处理操作按钮。
- 历史图片长按不会弹出操作遮罩。
- 正文图片单击不会发出 `asset-action`。
- 正文图片双击会发出当前图片相对路径对应的 `asset-action`。
- 现有后处理成功后正文替换回归测试继续通过。
- 运行相关前端组件测试、文生图相关测试和 `bun run typecheck`。

## 非目标

- 不调整图片预览历史版本切换逻辑。
- 不改变正文图片单击后的编辑器选区行为。
- 不为历史图片恢复任何生图或后处理快捷入口。
